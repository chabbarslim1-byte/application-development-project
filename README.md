# رواق (Riwaq) — تطبيق الكتب المسموعة والملخصات التاريخية والتونسية
> **عالم الكتب والقصص المسموعة والمقروءة باللغة العربية (Progressive Web App)**

تطبيق ويب تقدمي (PWA) خفيف وسريع، مصمم خصيصاً لتوفير تجربة قراءة واستماع صوتية سلسة للكتب والملخصات التراثية، مع تركيز خاص على **تاريخ تونس، ملاحم قرطاج، ورواد الأدب والفكر التونسي**.

---

## ✨ المميزات الرئيسية

### 1. محتوى ثقافي وتاريخي غني
* **الرصيد التونسي والمغاربي الأصيل** :
  * 📜 *أغاني الحياة* — أبو القاسم الشابي
  * ⚔️ *ملحمة حنبعل القرطاجي* — صراع قرطاج مع روما
  * ☕ *سهرت منه الليالي* — علي الدوعاجي وجماعة تحت السور
  * 🕌 *ابن خلدون في تونس* — نشأة الفكر في جامع الزيتونة وبلاط الحفصيين
  * 🏛️ *تأسيس القيروان وعقبة بن نافع* — منارة الحضارة في المغرب الإسلامي
  * 🌌 *حدّث أبو هريرة قال* — الرواية الوجودية لمحمود المسعدي
  * 🌸 *العزيزة عثمانة* — أميرة البر والإحسان التونسي
  * ⚖️ *أقوم المسالك في معرفة أحوال الممالك* — خير الدين باشا وحركة الإصلاح التونسية
* **الكلاسيكيات العالمية والتراثية المحفوظة** :
  * *مقدمة ابن خلدون*، *الأيام* لطه حسين، *حي بن يقظان* لابن طفيل، *كليلة ودمنة* لابن المقفع، *ألف ليلة وليلة*، *الأمير* لمكيافيلي، *تأملات* ماركوس أوريليوس، *رسالة الغفران* للمعرّي، *البخلاء* للجاحظ، *طوق الحمامة* لابن حزم.

### 2. تجربة صوتية متطورة (Audio TTS Engine)
* **دعم الأصوات العربية الطبيعية** (محسن لأجهزة سامسونغ وأندرويد).
* **أزرار تحكم كاملة** : تشغيل (Play)، إيقاف مؤقت (Pause)، استئناف (Resume)، وإيقاف تام (Stop).
* **التحكم في سرعة الإلقاء** : (0.8x، 1.0x، 1.25x، 1.5x).
* **مشغل عائم دائم (Floating Mini Player)** مع شريط تقدم حي ومؤشر ذبذبات صوتية.
* **استئناف الاستماع التلقائي** : يتذكر التطبيق آخر كتاب استمعت إليه لتمكينك من متابعته بنقرة واحدة.

### 3. واجهة مستخدم مريحة (Samsung & Mobile-First RTL)
* دعم كامل وتوجيه أصيل للغة العربية من اليمين لليسار (`dir="rtl"`).
* سمة داكنة فائقة التباين (AMOLED Dark Mode) مريحة للعين وموفرة لبطارية أجهزة سامسونغ.
* شريط تنقل سفلي إبهامي (Thumb-friendly Bottom Nav) للتنقل بين:
  * 📚 المكتبة الكاملة
  * 🇹🇳 تاريخ تونس
  * ⭐ المفضلة
  * ⚙️ الأصوات والإعدادات
* بحث فوري ذكي مع معالجة وتطبيع الحروف العربية والهمزات.
* نظام مفضلة محلي عبر `localStorage`.

### 4. تطبيق ويب تقدمي (PWA Installable & Offline)
* قابل للتثبيت كأي تطبيق أصلي على الهاتف عبر زر التثبيت أو خيارات المتصفح (Chrome / Samsung Internet).
* يدعم العمل بالكامل دون اتصال بالإنترنت بفضل `Service Worker` واستراتيجية `Cache-First`.

---

## 🚀 التشغيل والمعاينة المحلية

لتشغيل خادم محلي خفيف للمعاينة عبر المتصفح:

```bash
# الانتقال لمجلد المشروع
cd /root/riwaq

# تشغيل خادم بايثون على المنفذ 8080
python3 -m http.server 8080
```

ثم فتح العنوان في المتصفح :
👉 `http://localhost:8080` (أو عبر عنوان IP المحلي للهاتف في شبكة Wi-Fi).

## 📂 بنية المشروع

```text
riwaq/
├── index.html            # واجهة التطبيق الرئيسية (PWA Shell)
├── manifest.json         # مواصفات تثبيت التطبيق وتفاصيل الشاشة
├── sw.js                 # Service Worker للعمل دون إنترنت
├── css/
│   └── style.css         # أنماط التصميم والسمة الداكنة ودعم سامسونج
├── js/
│   ├── data.js           # قاعدة بيانات الكتب والملخصات التونسية والعالمية
│   ├── player.js         # محرك مشغل الصوت وتخصيص الأصوات والسرعة
│   └── app.js            # منطق البحث، المفضلة، التنقل، والـ PWA
├── icons/
│   ├── icon.svg          # الأيقونة المتجهة بدقة عالية
│   ├── icon-192.png      # أيقونة PWA 192x192
│   └── icon-512.png      # أيقونة PWA 512x512
├── index-1.html          # النسخة السابقة (محفوظة كمرجع)
└── index.old.html        # النسخة الأولى (محفوظة كمرجع)
```
